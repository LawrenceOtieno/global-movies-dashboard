Nature of this project

CineMetrics is a personal, non-commercial dashboard built for data-analysis and portfolio purposes. It's provided as-is, with no uptime guarantee, warranty, or service-level commitment of any kind.

Data accuracy

Ratings, revenue, season counts, and other figures come from third-party TMDB dataset exports and TMDB's public API, and reflect the state of that data at the time it was last synced. Source data can be incomplete, delayed, or occasionally inconsistent — see the dashboard for specific known caveats.

Acceptable use

This project is intended for personal, educational, and demonstration use. The underlying movie/TV data belongs to TMDB and its contributors — see TMDB's own terms for how their data may be used elsewhere.
