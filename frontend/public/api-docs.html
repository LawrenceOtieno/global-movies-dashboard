CineMetrics API Documentation

Flask backend — movie endpoints at /api/..., TV endpoints at /api/tv/.... All read-only (GET).

← Back to dashboard

Movies — /api/...

GET/api/health
Dataset load status and total movie count.
GET/api/summary-stats
Headline KPIs: total movies, average rating, total revenue, average runtime.
GET/api/movie-rankings
Top 10 / Bottom 10 movies by weighted rating.
GET/api/genre-distribution
Top genres by movie count, with percentages.
GET/api/decade-trends
Average rating by release decade.
GET/api/production-companies-performance
Top production companies by total revenue.
GET/api/production-countries-performance
Top production countries by average rating.
GET/api/cult-classics?limit=&sample_size=
Popularity-vs-rating quadrant data: hidden gems, overrated, and a background sample.
GET/api/recommend?title=&n=
Content-based recommendations for a movie title. Falls back to a live TMDB lookup if the title isn't in the local dataset.
GET/api/model-metadata
Recommender build stats (indexed movie count, vocab size, thresholds).

TV Shows — /api/tv/...

GET/api/tv/health
Dataset load status and total show count.
GET/api/tv/summary-stats
Headline KPIs: total shows, average rating, average episode runtime.
GET/api/tv/show-rankings
Top 10 / Bottom 10 shows by weighted rating (with a live TMDB season-count refresh for these ~20 shows).
GET/api/tv/genre-distribution
Top genres by show count, with percentages.
GET/api/tv/decade-trends
Average rating by first-air decade.
GET/api/tv/network-performance
Top networks by show count and average rating.
GET/api/tv/production-companies-performance
Top production companies by show count and average rating (no revenue data exists for TV).
GET/api/tv/production-countries-performance
Top production countries by average rating.
GET/api/tv/cult-classics?limit=&sample_size=
Same quadrant idea as movies, for shows.
GET/api/tv/recommend?title=&n=
Content-based recommendations for a TV show title, with the same live-TMDB fallback as movies.
GET/api/tv/model-metadata
Recommender build stats for the TV pipeline.

Notes

All movie data sourced from TMDB_movie_dataset_v11 (Kaggle). All TV data sourced from the asaniczka Full TMDb TV Shows Dataset (Kaggle), both re-exported from TMDB's public API. This is a personal project, not a public-facing commercial API — endpoints are unauthenticated and intended for local development use only.
