What this project actually is

CineMetrics is a personal data-analysis and recommendation project built on publicly available TMDB movie and TV datasets. It isn't a commercial product, doesn't have user accounts, and doesn't collect, store, or sell personal information of any kind.

What data this runs on

All movie and TV data (titles, ratings, genres, cast/crew-adjacent metadata) comes from public TMDB dataset exports and, optionally, live lookups against TMDB's public API for titles outside the local dataset. None of this is personal data about you — it's public information about films and television shows.

What's stored about you, specifically

Nothing. Searches you type into the recommender boxes are sent to this app's own backend to generate a response and are not logged, stored, or sent anywhere else.

Questions

This is a learning/portfolio project — there's no support line, but feel free to reach out to the developer directly if you have questions about how it works.
